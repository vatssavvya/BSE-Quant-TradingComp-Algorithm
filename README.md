# BSE-Quant-TradingComp-Algorithm

A quantitative trading algorithm developed for the **Bruin Software Engineers (BSE) Quant Track** at UCLA.

## Overview

This project focuses on developing an algorithmic trading strategy using historical financial market data. The objective is to construct a portfolio that maximizes risk-adjusted returns while maintaining effective risk management.

The competition provides approximately seven years of historical data for seven anonymized stocks, with strategies evaluated on three additional years of unseen data.

## Project Goals

- Develop and implement quantitative trading strategies.
- Analyze historical market data to identify trading opportunities.
- Optimize portfolio allocations and manage risk.
- Evaluate strategy performance through backtesting.

## Technologies

- Python
- NumPy
- pandas
- Quantitative Finance and Statistical Analysis

## Evaluation

Strategies are evaluated based on three primary metrics: **Sharpe Ratio (50%)**, **CAGR (30%)**, and **Maximum Drawdown (20%)**.
